# پرامپت اتصال یک ربات دیگر به API جوین اجباری (برای Antigravity)

این را روی پروژه‌ی **ربات دیگر** (رباتی که می‌خواهد استارت این ربات یا عضویت کانال را جوین اجباری بگذارد) به Antigravity
بدهید. قبلش در این ربات از `/admin` ← «🔑 API ربات‌ها» یک کلید بسازید و جاهای `<…>` را پر کنید.

```text
تو روی کد یک ربات تلگرام کار می‌کنی (به آن «ربات ما» می‌گوییم). می‌خواهیم استارت ربات «وینزون» و (اختیاری) عضویت در چند کانال
جوین اجباری ربات ما باشد و درستی‌اش را با API ربات وینزون بسنجیم؛ ربات ما خودش نمی‌تواند بفهمد کاربر ربات دیگری را استارت کرده.

اطلاعات:
- یوزرنیم ربات وینزون: <یوزرنیم بدون @>   (دکمه‌ی استارت: https://t.me/<یوزرنیم>)
- آدرس API: https://<دامنه‌ی ربات وینزون>/api/v1/
- کلید API: در متغیر محیطی WINZON_API_KEY ربات ما بگذار (در کد و گیت ننویس، در خروجی چاپ نکن). من مقدارش را می‌دهم.
- کانال‌های جوین اجباری (اختیاری): <@کانال۱, @کانال۲>  — ربات وینزون باید در این کانال‌ها ادمین باشد.

API (همه JSON، هم GET هم POST؛ کلید در هدر Authorization: Bearer <کلید> یا X-Api-Key):
- GET user?user_id=<آیدی عددی>
    {"ok":true,"user_id":123,"started":true,"blocked":false,"started_at":"…"}
    started یعنی یک بار /start زده و الان ربات وینزون را بلاک نکرده.
- GET check?user_id=<آیدی>&channels=@a,@b
    {"ok":true,"started":true,…,"channels":[{"chat":"@a","joined":true},{"chat":"@b","joined":false}],"all_joined":false,"passed":false}
    passed = استارت کرده و عضو همه‌ی کانال‌هاست. اگر کنار یک کانال error آمد (bot_not_admin، chat_not_found، network) یعنی
    عضویتش معلوم نشد.
- خطاها: 401 bad_key ، 400 bad_user_id یا bad_channels ، 429 rate_limited (سقف ۳۰۰ درخواست در ۱۰ ثانیه برای هر کلید).
- وب‌هوک (اختیاری): ربات وینزون به آدرسی که ما بدهیم POST می‌کند؛ بدنه JSON است با event یکی از start، block، unblock،
  join، leave، ping و فیلدهای user_id (و برای join/leave: chat_id، chat_username، chat_title). هدر X-Signature برابر
  hex(HMAC-SHA256(بدنه‌ی خام، کلید API)) است.

کارهایی که باید بکنی:
۱) کد ربات ما را بخوان و بگو با چه زبان و فریم‌ورکی نوشته شده، جوین اجباری فعلی (اگر هست) کجاست و پیام‌ها و دکمه‌ها کجا ساخته
   می‌شوند. همان سبک کد موجود را ادامه بده.
۲) قبل از کارهای اصلی کاربر (مثل جای فعلی جوین اجباری)، اگر کاربر هنوز تأیید نشده، پیامی بفرست با دکمه‌ی
   «🤖 استارت ربات وینزون» (لینک https://t.me/<یوزرنیم>)، دکمه‌ی هر کانال و دکمه‌ی «✅ عضو شدم».
۳) با «✅ عضو شدم»: check را با timeout حدود ۵ ثانیه صدا بزن. اگر passed بود قفل را باز کن و نتیجه را چند دقیقه برای همان
   کاربر کش کن تا هر پیام یک درخواست نشود. وگرنه دقیق بگو چه مانده (started=false: «اول ربات وینزون را استارت کن»؛
   joined=false: «عضو کانال … شو»). اگر API جواب نداد یا 5xx/429 بود، کاربر را برای همیشه گیر نینداز: خطا را لاگ کن و
   بگو چند ثانیه بعد دوباره بزند (یا در این حالت قفل را باز کن؛ از من بپرس کدام را می‌خواهم).
۴) (اختیاری، اگر ربات ما آدرس https عمومی دارد) یک مسیر وب‌هوک بساز: امضای X-Signature را با مقایسه‌ی زمان‌ثابت
   (hmac.compare_digest در پایتون، hash_equals در PHP) بسنج و اگر نادرست بود 401 بده؛ در start و join قفل همان user_id را
   باز کن، در block و leave دوباره ببند؛ همیشه سریع 200 جواب بده (کار سنگین را بعداً انجام بده). آدرس را به من بگو تا در
   پنل ربات وینزون («🔑 API ربات‌ها» ← «🔗 تنظیم وب‌هوک») ثبتش کنم و «🧪 تست وب‌هوک» را بزنم (رویداد ping).
۵) تست کن: یک بار با اکانتی که ربات وینزون را استارت نکرده (باید قفل بماند) و یک بار بعد از استارت (باید باز شود). با curl
   هم امتحان کن، ولی کلید را چاپ نکن (مثلاً read -s KEY و بعد -H "X-Api-Key: $KEY").
۶) در پایان گزارش بده: چه فایل‌هایی را عوض کردی، چطور تست کردی، متغیر محیطی جدید و آدرس وب‌هوک (اگر ساختی).
```
