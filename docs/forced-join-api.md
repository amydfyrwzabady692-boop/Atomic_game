# API جوین اجباری برای ربات‌های دیگر

با این API یک ربات دیگر می‌فهمد کاربرش **این ربات را استارت کرده** یا **عضو یک کانال شده** است؛ مثلاً وقتی استارت
این ربات یا عضویت کانال را جوین اجباری خودش گذاشته است. دو راه دارد که با هم هم کار می‌کنند:

1. **پرسیدن (pull):** کاربر در آن ربات «✅ عضو شدم» را می‌زند و آن ربات از این API می‌پرسد.
2. **وب‌هوک (push):** همان لحظه‌ای که کاربر این ربات را استارت یا بلاک کند، یا در کانالی که این ربات ادمینش است
   عضو شود یا بیرون برود، این ربات به آدرس وب‌هوک آن ربات خبر می‌دهد.

## گرفتن کلید

در پیوی ربات: `/admin` ← **🔑 API ربات‌ها** ← **➕ کلید تازه** ← یک نام (مثلاً نام ربات طرف مقابل). کلید (شروعش
`wz_` است) را فقط به همان ربات بدهید. همان‌جا می‌شود آدرس وب‌هوک گذاشت، آن را تست کرد، کلید را عوض کرد یا
موقتاً غیرفعال و حذف کرد. فقط مدیرانی که دسترسی «مدیران» دارند این بخش را می‌بینند.

## آدرس و احراز هویت

آدرس پایه: `https://<دامنه‌ی ربات>/api/v1/` (همان دامنه‌ی `MINIAPP_BASE_URL`).

کلید را به یکی از این سه شکل بفرستید:

- هدر `Authorization: Bearer <کلید>`
- هدر `X-Api-Key: <کلید>`
- پارامتر `key=<کلید>` در آدرس یا بدنه (برای کدهای ساده مثل `file_get_contents` در PHP)

همه‌ی آدرس‌ها هم `GET` و هم `POST` (فرم یا JSON) می‌پذیرند و جواب همیشه JSON با فیلد `ok` است.
سقف هر کلید ۳۰۰ درخواست در ۱۰ ثانیه است.

## آدرس‌ها

### `GET /api/v1/user?user_id=<آیدی عددی>`

(نام دیگر: `/api/v1/started`) — این کاربر ربات را استارت کرده است؟

```json
{"ok": true, "user_id": 123456789, "started": true, "blocked": false, "started_at": "2026-10-31T12:30:00+00:00"}
```

- `started`: یک بار `/start` زده و **الان ربات را بلاک نکرده** است (اگر بلاک کند `false` می‌شود و با آنبلاک یا
  `/start` دوباره `true`).
- `blocked`: ربات را بلاک کرده است.
- کاربری که هیچ‌وقت ربات را ندیده: `started: false` (خطا نیست).

### `GET /api/v1/check?user_id=<آیدی>&channels=@ch1,@ch2`

استارت + عضویت در کانال‌ها. `channels` می‌تواند `@username`، `username`، لینک `https://t.me/username` یا آیدی
عددی (`-100…`) باشد، با ویرگول جدا (حداکثر ۱۰). بدون `channels` کانال‌های جوین اجباری **همین ربات** بررسی می‌شوند.

```json
{
  "ok": true, "user_id": 123456789, "started": true, "blocked": false, "started_at": "…",
  "channels": [
    {"chat": "@ch1", "joined": true},
    {"chat": "@ch2", "joined": false, "error": "bot_not_admin"}
  ],
  "all_joined": false,
  "passed": false
}
```

- `passed` = استارت کرده **و** عضو همه‌ی کانال‌هاست.
- این ربات باید در هر کانال **ادمین** باشد تا عضویت را ببیند؛ وگرنه `joined: false` با `error: "bot_not_admin"` می‌آید
  (`chat_not_found` یعنی کانال پیدا نشد، `network` یعنی تلگرام جواب نداد).
- جواب «عضو است» تا ۱۰ دقیقه کش می‌شود، ولی خروج از کانال همان لحظه (با رویداد تلگرام) کش را پاک می‌کند؛ «عضو نیست»
  فقط ۱۵ ثانیه کش می‌شود.

### `GET /api/v1/me`

برای امتحان کلید: نام کلید، یوزرنیم ربات، داشتن وب‌هوک و کانال‌های جوین اجباری همین ربات.

### خطاها

| کد HTTP | `error` | معنی |
|---|---|---|
| 401 | `bad_key` | کلید نیست، اشتباه است یا غیرفعال شده |
| 400 | `bad_user_id` | `user_id` عدد مثبت نیست |
| 400 | `bad_channels` | `channels` قابل‌خواندن نیست |
| 429 | `rate_limited` | بیش از سقف درخواست |
| 405 | `method_not_allowed` | فقط GET و POST |

## وب‌هوک

اگر برای کلید آدرس وب‌هوک (https) گذاشته شود، این رویدادها با `POST` و بدنه‌ی JSON فرستاده می‌شوند:

| `event` | کی | فیلدهای اضافه |
|---|---|---|
| `start` | کاربر `/start` زد (برای هر کاربر حداکثر هر ۳۰ ثانیه یک بار) | `user_id`، `first` (اولین بار است؟) |
| `block` / `unblock` | کاربر ربات را بلاک یا آنبلاک کرد | `user_id` |
| `join` / `leave` | کاربر در کانالی که این ربات ادمینش است عضو شد یا بیرون رفت | `user_id`، `chat_id`، `chat_username`، `chat_title` |
| `ping` | دکمه‌ی «🧪 تست وب‌هوک» در پنل | `key` (نام کلید) |

همه‌ی بدنه‌ها `event`، `bot` (یوزرنیم این ربات) و `date` (زمان یونیکس) هم دارند:

```json
{"event":"start","bot":"winzon_bot","date":1761914000,"user_id":123456789,"first":true}
```

هدرها:

- `X-Event`: نام رویداد
- `X-Signature`: امضای HMAC-SHA256 **بدنه‌ی خام** با **کلید API** به صورت hex. همیشه بررسی‌اش کنید تا کسی جز این ربات
  نتواند رویداد جعلی بفرستد.

جواب `2xx` یعنی رسید. اگر جواب `5xx` باشد یا وصل نشود تا دو بار دیگر (بعد از ۲ و ۸ ثانیه) فرستاده می‌شود؛ `4xx` تکرار
نمی‌شود. نتیجه‌ی آخرین ارسال در جزئیات کلید در پنل دیده می‌شود. اگر سرور این ربات به آدرس وب‌هوک دسترسی ندارد،
`PARTNER_HTTP_PROXY` را در `.env` همین ربات بگذارید.

## نمونه‌ها

### curl

```bash
curl -s "https://bot.example.com/api/v1/user?user_id=123456789" -H "Authorization: Bearer wz_..."
```

```bash
curl -s "https://bot.example.com/api/v1/check?user_id=123456789&channels=@mychannel" -H "X-Api-Key: wz_..."
```

### PHP

```php
<?php
const API = "https://bot.example.com/api/v1/";
const KEY = "wz_...";

function started_our_bot(int $userId): bool {
    $json = @file_get_contents(API . "user?user_id={$userId}&key=" . urlencode(KEY));
    $data = $json ? json_decode($json, true) : null;
    return $data && $data["ok"] && $data["started"];
}

// وب‌هوک: امضا را بررسی کن
$body = file_get_contents("php://input");
$expected = hash_hmac("sha256", $body, KEY);
if (!hash_equals($expected, $_SERVER["HTTP_X_SIGNATURE"] ?? "")) { http_response_code(401); exit; }
$event = json_decode($body, true);
if ($event["event"] === "start") { /* کاربر $event["user_id"] ربات را استارت کرد */ }
http_response_code(200);
```

### Python

```python
import hashlib, hmac, httpx

API, KEY = "https://bot.example.com/api/v1/", "wz_..."

def started_our_bot(user_id: int) -> bool:
    data = httpx.get(API + "user", params={"user_id": user_id}, headers={"X-Api-Key": KEY}, timeout=5).json()
    return data.get("ok") and data["started"]

def valid_webhook(raw_body: bytes, signature: str) -> bool:
    expected = hmac.new(KEY.encode(), raw_body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, signature or "")
```

## جریان پیشنهادی در ربات طرف مقابل

1. پیام جوین اجباری: دکمه‌ی لینک `https://t.me/<یوزرنیم این ربات>` («استارت ربات …») و در صورت نیاز دکمه‌ی کانال‌ها، به‌علاوه‌ی
   دکمه‌ی «✅ عضو شدم».
2. با «✅ عضو شدم»: `check` (یا `user`) را صدا بزن؛ اگر `passed` (یا `started`) بود قفل را باز کن، وگرنه بگو کدام مانده.
3. اگر وب‌هوک داری، با رویداد `start`/`join` همان لحظه قفل کاربر را باز کن و با `block`/`leave` دوباره ببند
   (پرسیدن با «✅ عضو شدم» همیشه هم کار می‌کند).
4. اگر API در دسترس نبود (خطای شبکه یا 5xx)، کاربر را گیر نینداز یا چند ثانیه بعد دوباره بپرس.

## جوین اجباری خود این ربات

`/admin` ← **📢 جوین اجباری** ← **➕ افزودن کانال**: اول ربات را در کانال ادمین کنید، بعد یوزرنیم، لینک عمومی، آیدی عددی
یا یک پیام فورواردشده از کانال را بفرستید (برای کانال خصوصی ربات خودش لینک دعوت می‌سازد؛ دسترسی «دعوت کاربران با لینک»
لازم است). تا کاربر عضو کانال‌های فعال نشود، پیوی ربات، شرکت در مسابقه و ساخت مسابقه در گروه و مینی‌اپ پیام عضویت
نشان می‌دهند؛ کاری که کاربر می‌خواست (دعوت، شرکت در مسابقه، بخش کیف پول) بعد از «✅ عضو شدم» ادامه پیدا می‌کند. مدیران ربات
مستثنا هستند. اگر عضویت معلوم نشود (ربات ادمین نیست یا تلگرام جواب نمی‌دهد) کاربر گیر نمی‌افتد.
